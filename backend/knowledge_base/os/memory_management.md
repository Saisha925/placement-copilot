# Operating Systems: Memory Management

Memory management is the process of controlling and coordinating computer memory, assigning portions called blocks to various running programs to optimize overall system performance.

## Logical vs Physical Address Space
- **Logical Address (Virtual Address)**: Generated by the CPU; the address the process sees.
- **Physical Address**: The actual address in main memory (RAM).
- **Memory Management Unit (MMU)**: Hardware that maps logical addresses to physical addresses at runtime.

## Contiguous Memory Allocation
Memory divided into fixed or variable partitions.
- **First Fit**: Allocate the first hole that is big enough.
- **Best Fit**: Allocate the smallest hole that fits — minimizes wasted space but creates many tiny holes.
- **Worst Fit**: Allocate the largest hole — leaves larger leftover holes.
- **Internal Fragmentation**: Wasted space inside an allocated block.
- **External Fragmentation**: Wasted space outside allocated blocks (many small holes).

## Paging
Divides physical memory into fixed-size frames and logical memory into pages of the same size.
- **Page Table**: Maps page number → frame number for each process.
- **Page Table Base Register (PTBR)**: Points to the current process's page table.
- **Translation Lookaside Buffer (TLB)**: A fast hardware cache for recent page table lookups. Hit ratio determines effective access time.
- **Effective Memory Access Time (EAT)**: `hit_ratio * (TLB time + mem time) + (1 - hit_ratio) * (TLB time + 2 * mem time)`
- **Eliminates external fragmentation** but causes internal fragmentation (last page may not be full).

## Segmentation
Divides memory into variable-size segments (code, stack, heap, data).
- Each segment has a **base** (start address) and **limit** (size).
- Provides logical view of memory matching the programmer's perspective.
- Suffers from **external fragmentation**.

## Virtual Memory
Allows a process to execute without being fully loaded in memory.
- **Demand Paging**: Pages loaded only when needed (on page fault).
- **Page Fault**: When a process accesses a page not in memory → OS loads it from disk.
- **Swap Space**: Portion of disk used as overflow RAM.
- **Thrashing**: CPU spends more time swapping pages than executing — occurs when working set > available frames.

## Page Replacement Algorithms (when no free frame available)
- **FIFO (First-In-First-Out)**: Replace the oldest page. Simple but can suffer Belady's anomaly (more frames → more faults).
- **Optimal (OPT)**: Replace the page not used for the longest time in the future. Theoretical best — impossible to implement exactly.
- **LRU (Least Recently Used)**: Replace the page unused for the longest time in the past. Good approximation of Optimal. Implemented with counters or stack.
- **LRU Approximation (Clock / Second-Chance)**: Use a reference bit; give pages a second chance before replacing.

## Frame Allocation
- **Equal Allocation**: Each process gets equal number of frames.
- **Proportional Allocation**: Frames allocated based on process size.
- **Global Replacement**: Process can steal frames from other processes.
- **Local Replacement**: Process only replaces its own frames.
